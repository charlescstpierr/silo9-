# SILO 9 industrial surfaces

Original deterministic textures authored for this project, generated by `generate_textures.py` using Pillow and NumPy. They contain no downloaded image content and are not AI-edited images.

Four tileable 512×512 surface sets: painted wall panels, floor plates, smooth alloy and ventilation grates. Each has an albedo map, a tangent-space normal map derived from a height field, and a roughness map. Seeds are fixed so regeneration is repeatable.

Run: `python3 assets/industrial/generate_textures.py`.

Wall materials repeat in world space. The 88-metre floor uses planar repeating UVs to avoid three texture projections per pixel. Low graphics disables normal mapping while retaining albedo detail and all collision geometry.

`painted_panel_v2.png` is an original image generated for this project with the built-in imagegen tool on 2026-10-17. It supplies a painted color surface, not a screenshot or a borrowed game asset. The procedural generator does not reproduce that image.
