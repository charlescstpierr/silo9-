# Contrôle du binaire Linux exporté

Le parent a ouvert les neuf PNG de `packaged-native-verified` après l’exécution native. Le menu permet de commencer une nouvelle partie. La vue a avancé vers Décontamination. F éclaire le sol et affiche LAMPE ON ; Q révèle des signatures et fait passer l’énergie de 100 à 80. Échap ouvre la pause puis reprend avec la lampe allumée. Le second F éteint la lampe. Le menu principal réapparaît et Quitter termine le processus avec code 0.

Toutes les commandes d’entrée terminent avec code 0. Le journal ne contient ni ERROR ni SCRIPT ERROR. Il conserve l’avertissement de V-Sync non pris en charge par le pilote. La santé descend à 93 pendant l’approche d’une sentinelle ; le jeu n’est pas figé pendant ce contrôle.

Cette preuve porte sur un démarrage et ces commandes du binaire Linux exporté, sur X11 Compatibility 1280×720 et llvmpipe. Elle ne rejoue pas une mission complète, ne valide pas le son et n’exécute pas Windows. L’empreinte du binaire est vérifiée contre verification.json. Les sources de jeu sont celles de 64a9485 ; les outils de preuve copiés après l’export sont exclus du paquet Godot.
